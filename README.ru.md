> Языки: [English](README.md) · **Русский** · [日本語](README.ja.md)

**Индексирует и раскладывает большую коллекцию фото/видео** (протестировано на
60+ ГБ, рассчитано на 300+ ГБ) в чистую структуру папок — по **городу/стране**,
**человеку** или **событию** — с безопасностью в приоритете: по умолчанию dry‑run,
журнал перемещений и откат одной командой.

Sorta работает **локально** (ML‑модели для лиц, сцен и текста считаются на вашей
машине), **никогда не изменяет оригиналы** и предлагает и **CLI**, и пошаговое
**локальное веб‑приложение**.

![Sorta — локальное веб‑приложение: раскладка по городам, смена языка папок, разбор дублей, откат](docs/assets/hero.gif)

<sub>Локальное веб‑приложение (`sorta ui`) на синтетической демо‑коллекции — дерево городов, живое переключение языка папок (en/ru/ja) и разбор дублей.</sub>

> ⚡ **Для полноценного использования** — распознавание людей, глубокий
> VLM‑ярус или большие коллекции — рекомендуется **NVIDIA GPU (CUDA 13) с
> ≥ 4 ГБ VRAM** (**≥ 8 ГБ** для VLM‑яруса). На CPU всё тоже работает, просто для
> этих задач заметно медленнее — см. [Системные требования](#системные-требования).

> 📖 **Руководство пользователя:** [English](docs/guide/user-guide.en.md) ·

## Возможности

- **Сортировка по городам / людям / событиям** из одного индекса — смена режима не требует
  пересканирования.
- **Офлайн‑геолокация** (встроенная база GeoNames), GPS + вывод по сессиям; опционально
  онлайн Nominatim/OSM.
- **Быстрый базовый прогон по умолчанию.** Полный пайплайн по ~38 000 файлов идёт
  **67 минут**; с включённым глубоким VLM‑ярусом — **272**, поэтому он **выключен по
  умолчанию**, а его цена названа прямо на экране запуска. Глубокий ярус даёт то, чего
  быстрый не производит вовсе — класс «товар», — и он инкрементален, то есть платится
  один раз.
- **Лица и события — по желанию** (`--faces`/`--events` или галочки): это самые долгие
  стадии, и нужны они не всем.
- **Лица и люди:** локальные детекция и кластеризация (insightface); назовите и объедините
  кластеры, затем сортируйте или собирайте альбомы по человеку. **Имя, набранное в строке
  поиска, находит этого человека** — включая объединённые кластеры — точным отбором, а не
  ранжированием.
- **Поиск по коллекции словами** (многоязычный CLIP), и **любой запрос закрепляется
  отдельной вкладкой**. Встроенные срезы — тоже сохранённые запросы, так что закреплённый
  не является чем‑то второсортным.
- **Срезы про то, ЧТО на снимке и каким он вышел:** люди, дети, животные, скриншоты, мемы,
  документы, товары, скачанные картинки, размытые, закрытые глаза, низкое разрешение.
- **Каждый срез называет измеренное.** Подпись «модель считает эти кадры экранными;
  примерно каждый третий — обычная фотография, проверьте перед удалением» полезнее числа,
  притворяющегося приговором. Списки **ранжированы, а не отсечены порогом**: продукт
  упорядочивает, человек решает, где остановиться.
- **Дубликаты:** точные (blake3) и почти‑дубликаты (перцептивный хэш) с пакетным разбором.
- **Восстановление мягкого кадра** там, где оно помогает: по слепым парам модель выигрывает
  у обычного увеличения на **мелких** кадрах (62% против 10%) и ничего измеримого не даёт
  выше потолка — там действие и предлагается.
- **Альбомы:** любой срез или запрос собирается в названную папку **hardlink’ами** (почти
  без расхода места), копированием или перемещением — с выбором части кадров, если нужны
  не все.
- **Локальное веб‑приложение** (`sorta ui`), пять вкладок по тому, что они делают с вашими
  файлами, а не по стадиям пайплайна: **Обзор** (состояние коллекции одним экраном),
  **Разбор** (дубли, размытые, закрытые глаза), **Раскладка** (куда и по какому признаку),
  **Срезы** (запросы, закреплённое, встроенное), **Перемещения** (что сделала последняя
  партия и откат).
- **Три языка** интерфейса и имён папок: **ru / en / ja**.
- **Ничего не уходит с машины.** Все модели считаются локально; единственный исходящий путь
  — необязательный Nominatim, получающий округлённые **координаты**, а не фотографии.
- **Безопасно по устройству:** dry‑run, журнал и `undo`, сверка blake3, никогда не
  перезаписывает (суффиксы `_1`, `_2`).

## Системные требования

| | Профиль CPU (экстра `cpu`) | Профиль GPU (экстра `gpu`) |
|---|---|---|
| Железо | Любая машина x86‑64 | NVIDIA GPU + драйвер с поддержкой **CUDA 13** |
| VRAM | н/д | **~3 ГБ** база + лица (замерено на RTX 5090: CLIP ViT‑L 2.0 ГБ + buffalo_l 0.6 ГБ) — **≥ 4 ГБ** комфортно, **≥ 8 ГБ** для глубокого VLM‑яруса (Qwen2.5‑VL‑3B, ~7 ГБ оц.) |
| Скорость лиц/CLIP | Работает, но **медленно** (часы на большой коллекции с включёнными лицами/событиями) | Быстро — замер 28.07.2026: 24 196 фото, лица+события+junk ≈ **40 мин** без глубокого яруса; опциональный глубокий VLM‑ярус добавляет **+122 мин**, разово |
| Подходит для | Раскладки по городам + дублей на любой машине; небольших коллекций с включёнными лицами/событиями | Больших коллекций (300 ГБ+) с регулярно включёнными лицами/событиями |

Общее для обоих профилей: Python **3.11–3.14**, [`uv`](https://docs.astral.sh/uv/),
и **`exiftool` на PATH** (обязателен для метаданных HEIC/RAW/видео — без него Sorta
откатывается на Pillow, которая читает только JPEG/PNG/TIFF/WEBP и не читает видео).
Место на диске под индекс (SQLite) и миниатюры растёт с размером коллекции;
сортировка с `--copy` требует примерно ×2 размера коллекции, `--link`
(жёсткие ссылки) — почти ничего.

Цифры выше — с нашего железа, не гарантия. Полная раскладка, включая заметки по
RAM/VRAM — в [руководстве пользователя](docs/guide/user-guide.ru.md#2-требования).

## Быстрый старт

```bash
# Установка один раз — выберите ОДНУ из команд. Экстра пишется ВНУТРИ спецификации
# пакета и задаёт профиль под железо (`cpu` и `gpu` взаимоисключающие).
uv tool install "C:\path\to\sorta[cpu]"       # без NVIDIA GPU — кладёт `sorta` на PATH
uv tool install "C:\path\to\sorta[gpu]"       # NVIDIA GPU + драйвер CUDA 13
uv tool install "C:\path\to\sorta[gpu,vlm]"   # ...плюс глубокий VLM‑ярус
uv tool install -e "C:\path\to\sorta[gpu]"    # editable — для правок кода локально

sorta doctor                            # проверить, что реально встало (делать первым)
cp config.example.yaml config.yaml      # задайте `sources` и `language`
# exiftool обязателен для HEIC/RAW/видео — установите его сначала (см. «Требования»)

# Проще всего: веб‑приложение
sorta ui                                # http://127.0.0.1:8756 → Обработать папку → просмотр

# Или CLI
sorta index /путь/к/фото                # сканирование
sorta run                               # гео, landmarks, junk + хэши почти-дублей (города+дубли)
sorta run --faces --events              # ...плюс детекция лиц и построение событий
sorta sort --by city --dest /путь/к/разложенному            # dry-run план (CSV + HTML)
sorta sort --by city --dest /путь/к/разложенному --copy --apply   # применить (copy неразрушающий)
sorta undo                              # откатить последний батч при необходимости
```

> **У `uv tool install` нет флага `--extra`** — экстра живёт внутри закавыченной
> спецификации пакета, как выше. Без неё вы молча получите **CPU‑профиль**
> (`torch==2.13.0+cpu`) на машине с GPU. Ловится это командой `sorta doctor`: она
> печатает сборку torch, провайдеры onnxruntime, гео‑базу, а также пути лога и кэша
> превью.

Разрабатываете код сами? Используйте venv проекта (`uv sync --extra gpu --extra
dev`, активируйте его, дальше те же команды `sorta …` с живыми правками) — все
варианты установки, разбор вывода `sorta doctor`, ловушка
`onnxruntime`/`onnxruntime-gpu` и почему голый `uv run sorta …` — не путь, см.
[«Установка»](docs/guide/user-guide.ru.md#3-установка) в руководстве
пользователя.

Две вещи, которые стоит знать до большого прогона: Sorta держит **кэш превью**
(один декод на кадр, ≈150 КБ на фото — гигабайты на большой коллекции; посмотреть —
`sorta cache`, удалить — `sorta cache --clear`) и пишет **лог прогона** с таймингами
стадий в `%LOCALAPPDATA%\sorta\logs\sorta.log` (на остальных ОС —
`~/.cache/sorta/logs/sorta.log`). Подробности — в руководстве пользователя.

Полный обзор (с реальным выводом команд), справочник команд и конфигурации — в
[руководстве пользователя](docs/guide/user-guide.ru.md).

## Безопасность и приватность

- **Оригиналы никогда не изменяются.** Сортировка перемещает/копирует файлы; EXIF
  не переписывается.
- **Dry‑run по умолчанию;** каждая операция журналируется до выполнения;
  `sorta undo` откатывает её.
- **Ни одно изображение не покидает вашу машину.** Не «выключено по умолчанию» — кода,
  который бы его отправлял, не осталось: облачный провайдер именования событий удалён
  вместе с загрузкой картинок, и сторожевой тест не даёт этой строке вернуться незаметно.
  Единственный исходящий путь — необязательный геокодинг Nominatim, и он получает
  **округлённые координаты**, а не фотографию. Подробности — [SECURITY.md](SECURITY.md).
- **Документы** (паспорта, чеки, медицинские бумаги…) собираются в локальную
  review‑папку `_Документы/` и обрабатываются только на вашей машине.
- Веб‑приложение слушает только `127.0.0.1`.

Подробности — в [SECURITY.md](SECURITY.md).
